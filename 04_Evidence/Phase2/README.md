# Phase 2 Evidence Index

All Phase 2 screenshots are organized below by baseline verification and Phase 2 extensions (`A`–`E`), matching the structure in `CN_Project_Doc (1).pdf`.

> **Environment note:** As in Phase 1, all logical roles run on a single macOS host (`Pihus-MacBook-Pro.local`) using loopback aliases: `127.0.0.11` (Primary DNS), `127.0.0.12` (Primary Edge nginx), `127.0.0.13:3001` (Backend A), `127.0.0.14:3002` (Backend B), `127.0.0.15` (Backup DNS), and `127.0.0.16` (Standby Edge).
